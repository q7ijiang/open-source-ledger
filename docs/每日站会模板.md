# 开源账本每日站会模板

## 2026-09-18

- A：昨天做了X，今天做Y，卡在Z。
- B：昨天做了X，今天做Y，卡在Z。
- C：昨天做了X，今天做Y，卡在Z。

## 使用说明

1. 每个工作日更新一次，日期使用 YYYY-MM-DD。
2. A、B、C 每人都必须发一条消息。
3. 固定格式：昨天做了X，今天做Y，卡在Z。
4. X、Y、Z 必须写真实模块名和真实交付物，例如：
   - A：昨天做了BOM解析，今天做跨生态实体对齐，卡在缺少 npm 测试样例。
   - B：昨天做了AI许可证规则库，今天做血缘图构建，卡在无。
   - C：昨天做了测试数据准备，今天做中文清单生成，卡在需要确认高风险标注文案。
5. 没有阻塞时写“卡在无”。
6. 有阻塞时写清楚需要谁协助、需要什么输入、期望完成时间。
7. 站会后由对应负责人更新 docs/进度追踪.md 的状态。

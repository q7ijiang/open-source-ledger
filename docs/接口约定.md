# 开源账本接口约定

版本：v0.3  
适用模块：BOM 解析、跨生态实体对齐、证据链补全、AI 许可证规则库、中文清单生成、血缘图构建、Delta 检测、风险传播、增强层报告、全流程集成。

## 1. 通用约定

1. 所有 JSON 文件使用 UTF-8 编码。
2. 必填字段即使暂时没有值，也必须保留字段；未知值写 null。
3. `snapshot_id` 用于标识一次 BOM 快照。基础模式用 `basic-YYYYMMDD`；深度模式用 `t0`、`t1`。
4. `entity_key` 是一次分析中跨版本稳定的实体键，格式为 `asset_type:ecosystem/namespace/name`。
5. `canonical_id` 是当前版本下的唯一资产标识，格式为 `asset_type:ecosystem/namespace/name@version`；无版本时与 `entity_key` 相同。
6. 证据等级统一使用三级：

| 证据等级 | 含义 | 示例 |
|---|---|---|
| A | 官方或权威元数据直接证明 | PyPI、npm、Hugging Face API 返回的许可证字段，仓库 LICENSE 文件 |
| B | 工具产物或结构化依赖证据 | CycloneDX BOM、lockfile、模型卡结构化字段 |
| C | 推断、启发式或降级证据 | 同名对齐、模型卡文本推断、API 失败后的降级结果 |

7. 风险传播使用 weakest link 规则：路径证据等级取路径中最低等级。
8. 三级风险判定统一使用以下值：

| decision | 含义 |
|---|---|
| RISK_CONFIRMED | 路径上所有边证据等级为 A，规则明确适用 |
| RISK_POTENTIAL | 路径上存在 B 级边，规则可能适用 |
| UNDETERMINED | 路径上存在 C 级边、缺失祖先或冲突字段 |

## 2. 实体对齐状态

实体解析输出四类可解释状态：

| 状态 | 含义 | 是否进入并查集 |
|---|---|---|
| AUTO_MERGE | 确定性规则成立，可自动折叠为同一节点 | 是 |
| REVIEW | 中等信号或冲突信号，需要人工复核 | 否 |
| KEEP_SEPARATE | 明确冲突或跨生态默认边界，保持节点分开 | 作为否决约束 |
| UNDETERMINED | 信息不足，不合并并记录原因 | 否 |

资产对外使用以下 `merge_status`：

| merge_status | 含义 |
|---|---|
| MERGED | 该资产已由自动合并规则折叠 |
| REVIEW | 存在待人工复核的候选关系 |
| KEPT_SEPARATE | 未命中自动合并或明确保持分开 |
| UNDETERMINED | 候选存在但证据不足 |

每条候选关系日志至少包含：

| 字段 | 类型 | 含义 |
|---|---|---|
| status | string | AUTO_MERGE / REVIEW / KEEP_SEPARATE / UNDETERMINED |
| reason_code | string | 稳定的机器可读原因码 |
| supporting_evidence | object[] | 支持判定成立的证据 |
| conflicting_evidence | object[] | 与合并相冲突的证据 |
| rule_version | string | 合并规则版本，当前为 `merge-policy-v2` |
| confidence | number\|null | 兼容字段，不控制自动合并 |

## 3. 资产节点

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| entity_key | string | 是 | 跨版本稳定的实体键，不含版本 |
| canonical_id | string | 是 | 版本化资产标识，含版本；无版本时同 entity_key |
| asset_type | string | 是 | package / model / dataset / repository |
| name | string | 是 | 资产名称 |
| version | string\|null | 是 | 版本、标签或 commit；无法确定时为 null |
| purls | string[] | 是 | 关联的全部 purl；没有时为空数组 |
| license | string\|null | 是 | 许可证 SPDX 表达式或原始名称；未知时为 null |
| evidence_chain | object[] | 是 | 证据链列表；无证据时为空数组 |
| snapshot_id | string | 是 | 所属快照标识 |
| merge_status | string | 是 | MERGED / REVIEW / KEPT_SEPARATE / UNDETERMINED |
| reason_code | string | 是 | 本次资产对齐状态的原因码 |
| rule_version | string | 是 | 使用的合并规则版本 |

`evidence_chain` 中每个对象：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| evidence_level | string | 是 | A / B / C |
| source_api | string | 是 | pypi / npm / huggingface / cyclonedx |
| source_url | string\|null | 是 | 可追溯来源 URL；无 URL 时为 null |
| source_field | string | 是 | 原始字段路径，如 info.license |
| retrieved_at | string\|null | 是 | ISO 8601 时间；无法获取时为 null |
| status | string | 是 | ok / missing / network_error / inferred |
| raw_value | string\|object\|null | 是 | 原始证据值或结构化摘要 |

示例：

```json
{
  "entity_key": "model:huggingface/meta-llama/Llama-2-7b",
  "canonical_id": "model:huggingface/meta-llama/Llama-2-7b@main",
  "asset_type": "model",
  "name": "meta-llama/Llama-2-7b",
  "version": "main",
  "purls": ["pkg:huggingface/meta-llama/Llama-2-7b@main"],
  "license": "llama2",
  "evidence_chain": [
    {
      "evidence_level": "A",
      "source_api": "huggingface",
      "source_url": "https://huggingface.co/api/models/meta-llama/Llama-2-7b",
      "source_field": "cardData.license",
      "retrieved_at": "2026-09-18T02:30:00Z",
      "status": "ok",
      "raw_value": "llama2"
    }
  ],
  "snapshot_id": "basic-20260918",
  "merge_status": "MERGED",
  "reason_code": "PURL_COORDINATE_EXACT",
  "rule_version": "merge-policy-v2"
}
```

## 4. 血缘边

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| source | string | 是 | 起点资产的 canonical_id |
| target | string | 是 | 终点资产的 canonical_id |
| edge_type | string | 是 | derived_from / trained_on / depends_on |
| evidence_level | string | 是 | 该边证据等级：A / B / C |
| source_field | string | 是 | 证据来自的字段路径 |
| snapshot_id | string | 是 | 所属快照标识 |

边方向：

- `derived_from`：source 派生自 target。
- `trained_on`：source 训练使用了 target。
- `depends_on`：source 依赖 target。

示例：

```json
{
  "source": "model:huggingface/my-org/finetuned-ledger-model@t1",
  "target": "model:huggingface/meta-llama/Llama-2-7b@main",
  "edge_type": "derived_from",
  "evidence_level": "A",
  "source_field": "model_card.base_model",
  "snapshot_id": "deep-t1"
}
```

## 5. 事件对象

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| event_id | string | 是 | 事件唯一标识 |
| seed | string | 是 | 事件种子资产的 canonical_id；边变更事件（ancestor_*/dataset_*）为 edge.target（上游变化资产） |
| change_type | string | 是 | license_changed / ancestor_added / ancestor_removed / dataset_added / dataset_removed / evidence_downgrade / version_changed / version_upgraded |
| before | object\|null | 是 | 变更前状态；不存在时为 null |
| after | object\|null | 是 | 变更后状态；不存在时为 null |
| path | object[] | 是 | 从种子到受影响资产的血缘路径；种子自身无路径时为空数组 |
| evidence_level | string | 是 | 本次事件证据等级，按 weakest link 规则计算 |
| decision | string | 是 | RISK_CONFIRMED / RISK_POTENTIAL / UNDETERMINED |
| direction | object\|null | 否 | 仅 license_changed 事件：license_db.compare_direction 的结果（含 direction / risk_increased / ai_involved），用于许可证变更方向判断 |

变更事件语义：

- `license_changed`：同一 canonical_id 许可证变化；附带 `direction` 字段。
- `version_changed` / `version_upgraded`：同一 entity_key、不同 canonical_id（版本变化）。`version_upgraded` 特指从无版本引用升级为带版本；REVIEW / UNDETERMINED 资产不自动视为同一实体，不产生此类事件；同一快照内同一 entity_key 存在多个 canonical_id 且未全部 MERGED 时不自行折叠。
- `ancestor_added` / `ancestor_removed` / `dataset_added` / `dataset_removed`：血缘边新增/移除，seed 为 edge.target（上游变化资产）。

`before` 和 `after` 字段：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| canonical_id | string | 是 | 变更前后资产 canonical_id（版本化） |
| entity_key | string | 是 | 变更前后实体键（不含版本） |
| license | string\|null | 是 | 变更前后许可证 |
| purls | string[] | 是 | 变更前后 purl 集合 |
| snapshot_id | string | 是 | 变更前后快照标识 |
| merge_status | string\|null | 是 | 模块 2 合并状态：MERGED / REVIEW / KEPT_SEPARATE / UNDETERMINED |
| reason_code | string\|null | 是 | 对齐状态原因码 |
| rule_version | string\|null | 是 | 合并规则版本 |

`path` 中每个步骤：

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| source | string | 是 | 路径步骤起点 canonical_id |
| target | string | 是 | 路径步骤终点 canonical_id |
| edge_type | string | 是 | 边类型 |
| evidence_level | string | 是 | 该步骤证据等级 |
| source_field | string | 是 | 该步骤证据字段路径 |

示例：

```json
{
  "event_id": "evt-20261011-001",
  "seed": "package:pypi/example-parser@1.3.0",
  "change_type": "license_changed",
  "before": {
    "license": "MIT",
    "purls": ["pkg:pypi/example-parser@1.2.0"],
    "snapshot_id": "deep-t0"
  },
  "after": {
    "license": "GPL-3.0-only",
    "purls": ["pkg:pypi/example-parser@1.3.0"],
    "snapshot_id": "deep-t1"
  },
  "path": [
    {
      "source": "model:huggingface/my-org/ledger-model@t1",
      "target": "package:pypi/example-parser@1.3.0",
      "edge_type": "depends_on",
      "evidence_level": "B",
      "source_field": "requirements.txt"
    }
  ],
  "evidence_level": "B",
  "decision": "RISK_POTENTIAL"
}
```

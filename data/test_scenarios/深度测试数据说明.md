## 一、数据说明

- 两个文件均为**完整 CycloneDX 1.7 BOM**（各 8 个组件：4 个 AI 模型 + 1 个数据集 + 3 个 Python 库），可直接作为 delta_engine 的输入。
- 模拟故事：项目微调了 **ModelScope 基座模型 `modelscope/Llama-2-7b-ms`**（→ llama2-finetune-demo → llama2-chat-demo → quantized-demo），并使用了 instruction-dataset 训练数据。
- t0 → t1 之间**只注入两处许可证变化**（已验证：除许可证外，组件结构、purl、version、血缘关系完全一致）：

| 资产 | t0 许可证 | t1 许可证 | 场景 |
|---|---|---|---|
| modelscope/Llama-2-7b-ms（基座） | Apache-2.0 | Llama-2-Community | S1：宽松 → 严格 |
| instruction-dataset（数据集） | CC-BY-4.0 | CC-BY-NC-4.0 | S4：添加非商业限制 |

## 二、格式说明（2026-10-22 重构，对齐真 MS 格式）

> 背景：此前 t0/t1 基于 HF（Hugging Face）的 Llama-2-7b 构造，后来仅把命名空间从 hf 硬改成 ms，**格式仍是 HF 的**（`meta-llama/Llama-2-7b` 是 HF 命名空间、version 是 commit hash、缺 `cdx:modelscope:*` 字段）。
> 本次按组长要求，保留原测试场景，**按真 ModelScope 格式重写**，与 `ms_t0_bom.json` / `ms_t1_bom.json`（Qwen 场景）的字段规范保持一致：

| 字段 | HF 旧格式 | 真 MS 格式（本次） |
|---|---|---|
| 模型命名空间 | `meta-llama/Llama-2-7b`（HF） | `modelscope/Llama-2-7b-ms`（ModelScope 真实 ID） |
| bom-ref 前缀 | `cdxgen:ai:model:modelscope:` | `cdxgen:ai:model:ms:` |
| version | commit hash（如 `8d08c96`） | `master` |
| externalReferences | `https://www.modelscope.cn/...`（带 www） | `https://modelscope.cn/...`（无 www） |
| 模型属性 | `cdx:ai:modelFamily / cdx:ai:runtime` 等 | `cdx:modelscope:licenseName / cdx:modelscope:license / cdx:modelscope:sonModels` |
| metadata | 无 properties | `cdx:bom:componentTypes=modelscope`、`cdx:bom:componentNamespaces=modelscope` |
| evidence.methods | `https://www.modelscope.cn/api/v1/models/...` | 同左（API 地址） |

- 血缘链（pedigree.ancestors，证据等级与 ms_* 系列一致）：
  - `modelscope/Llama-2-7b-ms`（基座，无祖先）
  - `student-org/llama2-finetune-demo` ← 基座（A 级）
  - `student-org/llama2-chat-demo` ← finetune-demo（B 级）
  - `student-org/quantized-demo` ← chat-demo（C 级，lineage_backfill）
  - `student-org/instruction-dataset`（数据集，被 finetune-demo 的 modelCard.datasets 引用）

## 三、与接口约定 v0.3 的衔接

1. **t0/t1 保持标准 CycloneDX 输入格式**（purl / bom-ref / pedigree.ancestors / modelCard.datasets 原始形态）；`canonical_id`、`entity_key` 等版本化标识由 A 的 `bom_adapter.build_asset_identifiers()` 在解析时生成，不需要在输入里手工拼。
2. 血缘表达使用 CycloneDX 标准字段：
   - 微调关系 → `pedigree.ancestors[]`（finetune）
   - 训练数据关系 → `modelCard.modelParameters.datasets[]`
   - 普通依赖 → `dependencies[]`
3. **边证据等级口径**：按 v0.3，BOM 内 `pedigree.ancestors[].evidence_level` 已显式标注（A/B/C），解析层应优先透传 BOM 内标注，不强制降级。

## 四、B 跑验收时的预期

- delta_engine 应产出 **2 个 `license_changed` 事件**（evt：Llama-2-7b-ms、instruction-dataset），seed 指向变化资产自身（边变更事件 seed 取 edge.target，B 已修）。
- propagation 应沿血缘传播：Llama-2-7b-ms → llama2-finetune-demo → llama2-chat-demo → quantized-demo；instruction-dataset → llama2-finetune-demo。
- 验收判据：`path_certificates > 0`，且报告能呈现三种判定。

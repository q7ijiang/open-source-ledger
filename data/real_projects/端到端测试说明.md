- ✅ **链路通畅**：真实项目源码 → BOM（CycloneDX 1.7）→ 中文合规清单，全流程跑通，报告结构完整（统计摘要 / 资产明细 / 风险说明 / 免责声明）。

## 五、环境限制（如实记录）

1. **GitHub 主站不可达**：无法 git clone 真实仓库，样本改用 PyPI sdist / npm 发布包（官方源码，等效）。
2. **cdxgen 在线许可证元数据不可达**：本机 `cdxgen` 对 5 个真实项目生成的 BOM `licenses=null`（pypi.org / 部分 npm 元数据请求失败），导致对应清单全部"待确认"。已尝试 `--install-deps` + 清华 pip 源，仍无法获取。
3. **规避方式**：A 的 `data/sample_bom.json` 是 A 机器上预生成的高质量 BOM（70/72 带许可证），证明**完整链路在元数据可达的环境下工作正常**。

## 六、后续建议（10/05 验收前）

1. **联网环境重扫 5 个真实项目**：在可访问 pypi.org / registry.npmjs.org 的网络（或 A/B 的机器）下，用同一命令重跑 cdxgen 即可获得带许可证的 BOM，报告自动升级为完整识别。
2. 命令模板（Windows）：
   ```
   cdxgen -t python -t npm -t ai --evidence --no-install-deps --json-pretty -o <name>_bom.json .
   ```
3. 重扫后的 BOM 可放入仓库 `data/real_projects/`，作为基础层验收的数据资产。
4. AI 模型样本的补充：若需 5 个真实项目中含 HF 模型引用，可在联网环境克隆含 `from_pretrained` 的真实仓库扫描（当前 GitHub 不可达导致无法获取）。
